# Öğrenci Kayıt Sistemi - Frontend

Öğrenci kayıt sisteminin kullanıcı arayüzüdür.

## Kullanılan Teknolojiler

- HTML
- CSS
- JavaScript

## Çalıştırma

Frontend, VS Code Live Server kullanılarak çalıştırılabilir.

Frontend:
http://localhost:5500

## Backend

Frontend, öğrenci işlemleri için ayrı çalışan Node.js backend servisine istek gönderir.

Backend:
http://localhost:3000
